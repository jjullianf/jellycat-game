About the Jellycat Memory Game

The Jellycat Memory Game is a free online card matching game featuring 10 pairs of real Jellycat plush toys. Flip cards, find the matching pairs and beat your best time! One of several free Jellycat games available on Guess That Jelly.

Looking for more Jellycat games? Try the Jellycat Silhouette Game where you guess Jellycats from their shadow, or test your knowledge with the Jellycat True or False Quiz.

All games are completely free, work on mobile and desktop, and need no download or login. New Jellycats added regularly!
